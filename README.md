# Jay Krishna — AI/ML Engineer Portfolio

Live at [jaykrishna-17.github.io](https://jaykrishna-17.github.io/)

AI/ML Engineer portfolio specializing in Agentic AI, RAG, and real-time ML systems. Built with plain HTML/CSS/JS — no build step, no dependencies.

## Structure

- `index.html` — page content
- `css/style.css` — Dark Modern Tech theme (slate + teal/blue accent glows)
- `js/main.js` — nav, scroll reveals, stat counters, hero particle-network canvas
- `assets/resume/` — downloadable resume
- `assets/icons/` — favicon

## Local preview

Any static file server works, e.g.:

```bash
npx serve .
```
